Chapter 11: Finding the Peak — Optimization

"The derivative is zero at the peak — using derivatives to find the 'best' or 'most.'"

Problem 1 of 12 ⬜

Question: What is optimization in calculus?

(Hint: It's about finding the best or worst outcome.)

Think about finding the best price, the shortest time, or the greatest profit.

Optimization is the process of finding the maximum or minimum value of a function.

It answers questions like:

  • What price maximizes profit?
  • What dimensions minimize material?
  • What route is the shortest?

Answer: Optimization is finding the maximum or minimum value of a function.

Problem 2 of 12 ⬜

Question: Why is the derivative zero at both maximums and minimums?

(Hint: Think about the top of a hill or the bottom of a valley.)

At a peak, the curve changes from going up to going down. At that exact point, the slope must be zero.

The derivative is zero at both maximums and minimums because the curve is flat at those points.

  • At a maximum (top of a hill): slope changes from positive to negative → slope = 0 at the peak.
  • At a minimum (bottom of a valley): slope changes from negative to positive → slope = 0 at the bottom.

Answer: At the top of a hill, the slope is zero. At the bottom of a valley, the slope is zero.

Problem 3 of 12 ⬜

Question: Find the critical point of $f(x) = x^2 - 4x$.

(Hint: Find $f'(x)$, set it to zero, and solve.)

$f'(x) = 2x - 4$. Set to zero: $2x - 4 = 0$.

$f(x) = x^2 - 4x$

$f'(x) = 2x - 4$

Set $f'(x) = 0$: $2x - 4 = 0$

$2x = 4$

$x = 2$

Answer: $x = 2$

Problem 4 of 12 ⬜

Question: For $f(x) = -x^2 + 4x$, find the maximum value.

(Hint: Find the critical point, then plug it into $f(x)$.)

$f'(x) = -2x + 4$. Set to zero: $x = 2$. Then $f(2) = -(2)^2 + 4(2)$.

$f(x) = -x^2 + 4x$

$f'(x) = -2x + 4$

Set $f'(x) = 0$: $-2x + 4 = 0$ → $x = 2$

$f(2) = -(2)^2 + 4(2) = -4 + 8 = 4$

Since $f''(x) = -2 < 0$, this is a maximum.

Answer: $f_{\max} = 4$

Problem 5 of 12 ⬜

Question: For $f(x) = x^2 - 6x + 10$, find the minimum value.

(Hint: Find the critical point, then plug it into $f(x)$.)

$f'(x) = 2x - 6$. Set to zero: $x = 3$. Then $f(3) = 9 - 18 + 10$.

$f(x) = x^2 - 6x + 10$

$f'(x) = 2x - 6$

Set $f'(x) = 0$: $2x - 6 = 0$ → $x = 3$

$f(3) = (3)^2 - 6(3) + 10 = 9 - 18 + 10 = 1$

Since $f''(x) = 2 > 0$, this is a minimum.

Answer: $f_{\min} = 1$

Problem 6 of 12 ⬜

Question: What is the First Derivative Test?

(Hint: It uses the sign of the derivative before and after the critical point.)

Look at the sign of $f'(x)$ just before and just after the critical point.

The First Derivative Test uses the sign of the derivative to classify critical points:

  • Maximum: $f'(x)$ changes from + to -
  • Minimum: $f'(x)$ changes from - to +

Answer: If the derivative changes from + to -, it is a maximum. If it changes from - to +, it is a minimum.

Problem 7 of 12 ⬜

Question: What is the Second Derivative Test?

(Hint: It uses the second derivative at the critical point.)

$f''(x)$ is the derivative of $f'(x)$. Its sign tells you which way the curve is bending.

The Second Derivative Test uses the second derivative at the critical point:

  • Maximum: $f''(x) < 0$ (curve bends downward)
  • Minimum: $f''(x) > 0$ (curve bends upward)

Answer: If $f''(x) < 0$, it is a maximum. If $f''(x) > 0$, it is a minimum.

Problem 8 of 12 ⬜

Question: A company's profit is $P(x) = -x^2 + 10x - 16$, where $x$ is the number of units sold. Find the number of units that maximizes profit.

(Hint: Find $P'(x)$, set to zero, and solve.)

$P'(x) = -2x + 10$. Set to zero: $-2x + 10 = 0$.

$P(x) = -x^2 + 10x - 16$

$P'(x) = -2x + 10$

Set $P'(x) = 0$: $-2x + 10 = 0$ → $x = 5$

$P''(x) = -2 < 0$, so this is a maximum.

Answer: $x = 5$ units

Problem 9 of 12 ⬜

Question: A farmer has 100 meters of fencing to enclose a rectangular field. What dimensions maximize the area?

(Hint: Let $x$ = width, $y$ = length. Perimeter: $2x + 2y = 100$. Area: $A = xy$.)

, Length =

$2x + 2y = 100$ → $y = 50 - x$.

$A(x) = x(50 - x) = 50x - x^2$.

Find $A'(x)$, set to zero, and solve.

Perimeter: $2x + 2y = 100$ → $y = 50 - x$

Area: $A(x) = x(50 - x) = 50x - x^2$

$A'(x) = 50 - 2x$

Set $A'(x) = 0$: $50 - 2x = 0$ → $x = 25$

$y = 50 - 25 = 25$

$A''(x) = -2 < 0$, so this is a maximum.

Answer: Width = 25m, Length = 25m

Problem 10 of 12 ⬜

Question: A box with a square base and an open top must have a volume of 32 cubic feet. What dimensions minimize the amount of material used?

(Hint: Let $x$ = base side, $h$ = height. Volume: $x^2 h = 32$. Surface area: $SA = x^2 + 4xh$.)

, Height =

$h = 32/x^2$. $SA(x) = x^2 + 4x(32/x^2) = x^2 + 128/x$.

$SA'(x) = 2x - 128/x^2$. Set to zero and solve.

Volume: $x^2 h = 32$ → $h = 32/x^2$

Surface area (no top): $SA = x^2 + 4xh = x^2 + 4x(32/x^2) = x^2 + 128/x$

$SA'(x) = 2x - 128/x^2$

Set $SA'(x) = 0$: $2x = 128/x^2$ → $2x^3 = 128$ → $x^3 = 64$ → $x = 4$

$h = 32/4^2 = 32/16 = 2$

$SA''(x) = 2 + 256/x^3$. At $x = 4$, $SA''(4) = 2 + 256/64 = 2 + 4 = 6 > 0$, so this is a minimum.

Answer: Base = 4ft, Height = 2ft

Problem 11 of 12 ⬜

Question: A company sells a product. The demand is given by Price = $100 - 2x$, where $x$ is the number of units sold (in thousands). Revenue = Price × Units. Find the number of units that maximizes revenue.

(Hint: $R(x) = x(100 - 2x) = 100x - 2x^2$.)

$R(x) = 100x - 2x^2$. $R'(x) = 100 - 4x$. Set to zero and solve.

Price = $100 - 2x$

Revenue = $R(x) = x(100 - 2x) = 100x - 2x^2$

$R'(x) = 100 - 4x$

Set $R'(x) = 0$: $100 - 4x = 0$ → $x = 25$

$R''(x) = -4 < 0$, so this is a maximum.

Answer: $x = 25$ thousand units (25,000 units)
