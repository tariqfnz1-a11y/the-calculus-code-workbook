# The Calculus Code — Interactive Workbook

This is the interactive workbook for **"The Calculus Code"** eBook.

## Features

- Over 140 practice problems
- Instant answer checking
- Hints and step-by-step solutions
- Progress tracking (saves in your browser)
- Mobile-friendly

## How to Use

1. Start from the [Dashboard](index.html)
2. Select a chapter
3. Solve problems and check your answers
4. Track your progress automatically

## Chapters

- **Part 1:** Foundations (Chapters 1-4)
- **Part 2:** Core Calculus (Chapters 5-8)
- **Part 3:** Advanced Topics (Chapters 9-11)
- **Challenges:** Epilogue, Police Proofs, Mixed Review
