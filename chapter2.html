Chapter 2: Input, Output, and Machines

"A function is a rule that connects an input to an output."

Problem 1 of 12 ⬜

Question: What is a function in mathematics?

(Hint: Think about a vending machine.)

A function is like a machine. You put something in, it follows a rule, and something comes out.

A function is a rule that takes an input, does something to it, and produces an output.

Think of it like a vending machine: Input = $1, Machine = rule, Output = snack.

Problem 2 of 12 ⬜

Question: What are the four ways we describe a function?

(Hint: The "Rule of Four.")

Think about the four ways you can describe something: with words, with numbers, with a picture, and with a formula.

The Rule of Four describes functions in four ways:

  1. Verbal — In plain English
  2. Numerical — With numbers in a table
  3. Visual — With a graph or picture
  4. Algebraic — With symbols (a formula)
Problem 3 of 12 ⬜

Question: If the rule is "multiply by 4," what is the output when the input is 5?

Multiply the input by 4.

Input = 5

Rule = "multiply by 4"

Output = 5 × 4 = 20

Problem 4 of 12 ⬜

Question: In the function $y = 3x$, what is $y$ when $x = 7$?

Multiply $x$ by 3.

$y = 3x$

When $x = 7$: $y = 3 \times 7 = 21$

Problem 5 of 12 ⬜

Question: What is the verbal rule for the function $y = x + 5$?

What operation is being done to $x$ in $y = x + 5$?

$y = x + 5$ means: "Add 5 to the input."

Whatever you put in for $x$, you add 5 to get $y$.

Enter the rule as: y = 2x + 3

Look at the pattern: when $x$ goes up by 1, $y$ goes up by 2. So the rule has "$2x$" in it. Then look at what happens when $x = 0$.

When $x$ goes up by 1, $y$ goes up by 2. So the rule has $2x$.

When $x = 0$, $y = 3$. So we add 3.

Problem 8 of 12 ⬜

Question: In the function $y = 4x + 2$, what is $y$ when $x = 3$?

Multiply $x$ by 4, then add 2.

$y = 4x + 2$

When $x = 3$: $y = 4(3) + 2 = 12 + 2 = 14$

Problem 9 of 12 ⬜

Question: What does the "Mental Zoom" help you do when reading a graph?

Think about what you see on a graph: does it go up? Down? Flat? Curved?

The Mental Zoom helps you read a graph by asking:

  • What happens to $y$ when $x$ goes up?
  • Is it increasing or decreasing?
  • Is it steep or flat?
  • What's the overall shape?
Problem 10 of 12 ⬜

Question: Complete this sentence: "Multiplication is just repeated ________."

$3 \times 5 = 3 + 3 + 3 + 3 + 3$. What operation is being repeated?

"Multiplication is just repeated addition."

Example: $3 \times 5 = 3 + 3 + 3 + 3 + 3 = 15$

Similarly, division is repeated subtraction.

Problem 11 of 12 ⬜

Question: A plumber charges \$50 per hour plus a \$30 call-out fee. Write a function for the total cost $C$ in terms of hours $h$.

Enter the rule as: C = 50h + 30

Total cost = (rate × hours) + call-out fee.

Rate = \$50 per hour

Call-out fee = \$30

Total cost = (50 × hours) + 30

$C = 50h + 30$

Problem 12 of 12 ⬜

Question: If the input is 6 and the output is 18, and the rule is "multiply by $k$," what is the value of $k$?

Output = Input × $k$. So $18 = 6 \times k$.

Output = Input × $k$

$18 = 6 \times k$

$k = 18 \div 6 = 3$

Answer: $k = 3$
